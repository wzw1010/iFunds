# iFunds - 基金持仓跟踪工具

一个极简、优雅的基金持仓跟踪 PWA 应用。添加基金代码、成本与份额，即可实时获取最新净值，并自动计算盈亏与收益率。

## ✨ 特性

- 📊 **实时净值**：基于腾讯证券接口，获取最新基金净值。
- 📈 **多维盈亏**：展示最新盈亏、持有盈亏及对应收益率。
- 🎨 **双态装饰条**：深色（当日有效） / 浅色（非当日），直观分辨数据新鲜度。
- 🔏 **隐私模式**：连续点击顶部卡片 3 次，隐藏敏感数字。
- ✏️ **批量编辑**：一键进入编辑模式，批量修改成本价与份额。
- 💾 **数据管理**：支持导出/导入 JSON 配置，方便备份与迁移。
- 📱 **PWA 支持**：可添加至手机主屏幕，离线仍可查看缓存数据。

## 🛠️ 技术栈

- 纯 HTML/CSS/JS，无框架
- JSONP 跨域请求基金数据
- CSS Grid + Flexbox 布局
- Service Worker 离线缓存
- Web App Manifest (PWA)

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 主程序，包含所有样式和逻辑 |
| `manifest.json` | PWA 配置文件 |
| `sw.js` | Service Worker，用于离线缓存 |
| `icon-1024.png` | 应用图标 |

## 📝 使用技巧

- **添加基金**：输入 6 位基金代码，自动识别名称。
- **刷新净值**：点击底部“刷新净值”按钮，获取最新数据。
- **编辑/删除**：点击“批量编辑”进入编辑模式。
- **隐私保护**：连点顶部摘要卡片 3 次，隐藏所有数字。
- **导出备份**：在“数据管理”中导出配置文件。
